# 🚀 HTB_Machines - Hack The Box Walkthroughs

Welcome to my Hack The Box (HTB) repository! 

This repository serves as a personal knowledge base and portfolio documenting my journey through various **Hack The Box** machines. It contains my methodologies, commands used, and step-by-step walkthroughs for both Linux and Windows environments.

## 📂 Repository Structure
Each machine has its own dedicated folder containing a detailed Markdown (`.md`) file. As I continue to root more machines and explore new vulnerabilities, this repository will be continuously updated.

**Topics covered across these walkthroughs include:**
*   Enumeration & Reconnaissance
*   Web Exploitation
*   Active Directory Attacks
*   Privilege Escalation (Linux & Windows)
*   Pivoting & Lateral Movement
